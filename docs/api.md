# API v1

Поверхность зеркалит `react-native`; всё из таблиц ниже импортируется из `"react-native"` (через vite-пресет) или напрямую из `"react-native-gtkx"`. Полнота проверяется скриптом `npm run docs:check` (каждый публичный экспорт обязан упоминаться в этом файле).

## Главные отличия от React Native (сводно)

1. **Десктоп, а не мобильный**: `Modal` — настоящее окно; `runApplication` принимает title/размеры; жесты — мышь (hover есть, тач-жестов нет);
2. **Node.js-рантайм**: доступен весь npm/Node (fs, sqlite, napi) — «нативные модули» пишутся как обычные Node-модули; RN-библиотеки с iOS/Android-кодом не работают;
3. **Text** всегда сжимаем (ellipsize) — длинное слово не раздвигает раскладку, в отличие от строгого RN-минимума;
4. **transform** сейчас только translate в `Animated.View`;
5. **overflow-дети**: ребёнок, спозиционированный за пределами родителя, может влиять на «естественные» размеры GTK-контейнеров (RN просто рисует поверх) — системное решение в работе (PRD, ветка B);
6. Типы поставляются TS-исходниками; бандлер (vite-пресет) собирает пакет вместе с приложением.
